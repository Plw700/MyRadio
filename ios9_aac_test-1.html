Тест AAC-потока

Нажми «Запустить поток». Этот тест использует нативный HTML5-плеер и показывает события Safari. Ссылка вставляется отдельно, чтобы не хранить временный токен в файле.

Статус: ожидание ссылки.

Журнал событий

Здесь появятся события audio.

Важно: токен в URL может быть временным. Не публикуй HTML с рабочей ссылкой. Если страница открыта через file://, это нормально для такого теста, но некоторые серверы могут ограничивать запросы по User-Agent или Referer.
